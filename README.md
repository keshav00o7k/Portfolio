# 🚀 Keshav Goyal Portfolio - Frontend

This is the frontend client for Keshav Goyal's personal developer portfolio, built with React 19, Vite, Tailwind CSS, and modern CSS architectures.

For complete project documentation, project architecture, live platform URLs, and setup guide, please see the [Root README.md](../README.md).

### Quick Commands
```bash
# Run Development Server
npm run dev

# Build for Production
npm run build

# Preview Production Build
npm run preview
```
